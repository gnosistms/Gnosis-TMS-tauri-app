Hans asked to prepare DLE results before automated testing so repeated studies do not require CAPTCHA interaction. Computer-use policy still requires action-time confirmation for each live challenge; cached public evidence can be reused without interacting with a challenge. Existing studies and old research files must remain intact.

## Implementation

1. Add a persistent, app-owned cache of verified DLE results, keyed by the source request URL and independent of glossary, target language, study and AI model. Keep source URLs, retrieval time, complete structured dictionary evidence and an explicit cache indicator. Store successful entries and verified no-entry results only; never store a CAPTCHA, timeout or failed retrieval as dictionary evidence.
2. Make the native DLE reader consult that cache before opening a window, and save usable live results for later reuse. Perform disk work outside the async IPC path. Preserve the existing challenge behavior on a genuine cache miss; no automatic CAPTCHA interaction or new retrieval fallback.
3. Prepare cache entries from successful, source-attributed DLE data already saved by the old research tool. Import copies only; preserve original files. Produce a preparation report that distinguishes prepared entries from missing/unreachable evidence for the complete seven-term list.
