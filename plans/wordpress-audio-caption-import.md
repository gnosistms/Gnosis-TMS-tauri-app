# WordPress audio captions

1. Look up the inserted audio file by URL. Import a library caption when available and use the description when WordPress returns an empty caption or an automatically generated excerpt of the audio player and description. Retain links in the author's text.
2. Apply the background result to the matching language's caption even if the translator is editing another part of the row. Preserve edits to the caption itself.
3. Verify the reported recording, description-only audio, player-only metadata, and the editor's handling of concurrent edits. Run the existing export-panel regression and repository checks before merging.
