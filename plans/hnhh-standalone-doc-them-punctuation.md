# HNHH footnote link punctuation

1. Read the Gnosis VN project in book order and inspect each footnote in numbered chapters 1–14. Check the surrounding words wherever a link reads “Đọc thêm”.
2. Put one period inside each standalone link caption. Reuse an existing period immediately after the link when present. Preserve every destination and the rest of each row.
3. Verify the changes against the original rows and reread the saved footnotes from the team project.

## Result

Chapters 1–14 contain 97 standalone “Đọc thêm” links. Six needed a period and seven had a period immediately after the link. The corrections affected chapters 2, 5, and 6. Rereading the 316 footnotes confirmed the captions and destinations in the saved project at `088b1ae0`.
