# Gnosis TMS

A local-first desktop translation management system built with Tauri. Translation
teams manage projects, glossaries, and QA lists backed by GitHub repositories.

See [CONTRIBUTING.md](CONTRIBUTING.md) for development setup and contribution
guidelines.
