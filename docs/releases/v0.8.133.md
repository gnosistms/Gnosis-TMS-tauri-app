# Gnosis TMS 0.8.133

## Editor access

- Keep chapters editable when a project refresh finishes after navigating away
  from Projects. Discard abandoned refresh results and late progress updates
  before they can replace the active chapter's project context.
- Start a fresh project load when returning to Projects while an abandoned
  refresh is still cleaning up.

## Footnote editing

- Show a single focus outline around the footnote being edited. Footnotes remain
  individually editable, one at a time, without an outline around the whole group.
- Preserve a visible keyboard-focus indicator on closed footnotes.
