# Gnosis TMS 0.8.121

## Review context and project search improvements

- AI Review remains visible after you edit a translation. Its text is shown with a diff against the current editor content, so you can make several edits while referring to the review. Outdated suggestions cannot be applied until you request a fresh review.
- Project search has an optional case-sensitive mode. Results, highlighted excerpts, and the search opened in the editor consistently use the selected mode.
