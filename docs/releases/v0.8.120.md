# Gnosis TMS 0.8.120

## More reliable saves and resource sync

- Editor text and formatting saves can recover once from an expired GitHub session without requiring you to repeat the edit.
- Concurrent access checks no longer compete for the same temporary cache file. Cached access is also tied to the login that obtained it.
- Glossary and QA-list sync now checks the current remote branch before reconciling local changes, including when repository details are stale.
- If another writer updates the remote during sync, Gnosis makes one further reconciliation attempt. Conflicts and unrelated histories still stop sync and preserve local commits for review.
- Access-check failures now carry more precise, privacy-preserving diagnostics to help investigate remaining blocked saves.
