# Gnosis TMS 0.8.129

## Sentence grouping for subtitles

- Switch from Standard to Group fragments to read and edit subtitle fragments
  together as complete sentences. Standard remains the default view.
- Groups follow sentence punctuation. For long sentences without punctuation,
  optionally split at pauses using thresholds from 0.5 to 3 seconds.
- Edit around numbered separators while preserving each subtitle's original
  timing. Leave individual fragments blank when needed. Marker errors can be
  repaired in a draft for you to review before saving.
- Translate, review and check glossary terms across a complete group, including
  terms split between fragments. Group actions update the member fragments;
  conflicts and deleted rows remain separate.

## Editor improvements

- Grouped Review combines each fragment's latest change into one sentence-wide
  diff. Last update and AI Review stay open; History retains fragment selection.
- Glossary research is available from every language panel and starts with the
  language you selected.
- Improve scrolling with the grouping controls, preserve fresh translations in
  clean edit sessions, and safely apply grouped AI drafts after switching views.
