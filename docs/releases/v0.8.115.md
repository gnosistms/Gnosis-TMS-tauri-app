# Gnosis TMS 0.8.115

## More reliable glossary hints for AI features

- AI Assistant chat and AI Translate now wait for the chapter's linked glossary to finish loading (or retry it after a prior failure) before answering, instead of silently proceeding with no glossary context if asked or run too soon after opening a chapter.
- Loading a chapter's glossary now waits for any in-flight glossary term saves to settle first (bounded to 10 seconds), so it can no longer read stale or in-progress data mid-save.
