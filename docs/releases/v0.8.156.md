# Gnosis TMS 0.8.156

## PDF exports

- Chapter and book PDFs can print QR codes for footnote links. New exports use **Print QR codes** by default. Choose **Print URLs in parentheses** or **Clickable links only** when preparing a different edition.
- Footnote text wraps around the codes and returns to the full text width with normal line spacing. Neighboring codes share a row when it saves space. Shared codes carry their footnote numbers, and multiple links in one note use matching lettered labels such as **15a** and **15b**.
- Where a publisher provides a verified short link, Gnosis TMS can use it to print a smaller code. Links in the digital PDF still open the destination chosen in the editor.
- Gnosis TMS saves prepared images on disk so later PDF exports can reuse them after an app restart.

## Book review

- The redundancy check shows progress while it compares footnotes. Footnote results appear together when the check finishes. Image choices and the scroll position stay in place as progress updates arrive.

## Glossaries and QA lists

- Use **Insert link** in glossary and QA term editors to add a web link to selected text.

## Project files

- Permanent removal is available only for files already in the deleted list.
