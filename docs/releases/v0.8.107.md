# Gnosis TMS 0.8.107

## More reliable glossary term editing

- Glossary terms save correctly when repository details are still loading.
- Duplicate source variants are rejected before they are saved. The conflicting
  variants are marked in red, with a clear message above the term fields.
- If a save is rejected, the glossary keeps the saved row intact and reopens
  your draft so you can correct it.
- Deleting a glossary term updates filtered search results immediately; a manual
  refresh is no longer required.
