# Gnosis TMS 0.8.135

## Redundancy checks for book exports

- Review repeated images and footnotes in a new export step before choosing the
  output format. Keep the first occurrence by default, or select additional
  occurrences with **Include in export**.
- See image thumbnails and the chapters that contain them. Both image and
  footnote reports use the chapter numbers and titles from the book arrangement.
- Match linked images by URL and uploaded images by their contents, with cached
  results and inclusion choices saved locally. Image checks display independently
  while footnotes are processed.
- Find footnote candidates by sorting the reversed text before each note and
  comparing neighboring entries. Cached word-frequency counts keep repeated
  exports fast; AI separates genuinely redundant meanings from different or
  complementary explanations.
- Apply these choices to the exported book while preserving the source chapters.
  Changed images or footnotes are checked again before export.

## Book arrangement and previews

- Set chapter titles and optional numbering separately for each language.
- Save book arrangements and export settings through GitHub. A **Settings loaded**
  notice appears only when the loaded configuration meaningfully differs from
  local settings.
- Preview title pages as typeset PDFs and use consistent print typography,
  contents spacing, page sizes, captions, and ornaments throughout the book.
- Include chapter H1 headings in the table of contents when selected.
- Keep chapter controls, long titles, editing focus, and scrolling stable while
  previews and background updates finish.
- Keep split title-page titles on one line in PDF running headers.
- Download up to 12 linked PDF images concurrently while four workers process
  them, with a bounded queue to limit waiting image data in memory.

## Editor and glossary fixes

- Keep your own comments marked as read across navigation and reloads.
- Keep attribution prompts from overlapping after switching windows.
- Refresh glossary hover cards after term edits and background synchronization.
- Create glossary entries from selected editor text, with a target translation
  required before saving.
- Separate adjacent footnote markers with superscript commas.
- Preserve projects-page scrolling during background updates and improve
  diagnostics for slow or stuck startup.
- Support native undo when inserting caption hyperlinks.
- Refine research-studio progress, review, and navigation.
