# Gnosis TMS 0.8.134

## Project book export

- Export a whole project from its card using a two-page book composer.
- Choose an export language, include or exclude chapters, and drag chapters into
  the order you want. Chapters missing the selected language are excluded.
- Add and edit title pages, copyright pages, dedications, tables of contents,
  publisher logos, and full-page illustrations with optional captions.
- Keep a separate layout and section content for each language. Export settings
  save automatically on this computer, and custom contents titles are remembered
  for future books in the same language.
- Create PDFs using the same chapter typography, drop caps, and ornaments as
  individual chapter exports. Contents page numbers and links follow the final
  layout, including when the contents is placed at the end.
- Export arranged books to DOCX and ordered elements to Vellum. Vellum uses its
  own layout and contents rules, with simplified title and illustration pages.

## Export improvements

- Keep Save visible with a disabled spinner while PDF fonts are checked.
- Use the app's standard tooltips throughout the export modal, including visible
  WordPress hints in a scrolling site list.
- Prepare Vellum images in a separate Gnosis workspace so copying images does
  not interfere with Vellum's active previews.
