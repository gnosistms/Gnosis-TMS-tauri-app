# Gnosis TMS 0.8.128

## Subtitle translations

- Add translations now accepts SRT subtitle files. Subtitle chapters require an
  SRT upload, with format validation before alignment begins.
- Subtitles with identical start times match automatically. This avoids the
  slower document alignment process and keeps the original chapter timing.
- If more than 5% of the new subtitles have no exact start-time match, you can
  cancel or try matching by the largest available time overlap. A second warning
  appears if more than 5% remain unmatched.
- Overlap matching checks up to 20 text pairs with AI. If more than three do not
  appear to have equivalent meaning, a warning shows the mismatched examples
  before you decide whether to save.
- Cancel processing from the alignment progress dialog. Cancellation stops work
  before saving begins; a save already in progress is allowed to finish.

## Glossary tooltips

- Source-text glossary popups once again show their footnotes, including
  formatted text and links.
