# Gnosis TMS 0.8.109

## Preserve unsaved editor drafts

- Background sync and manual refresh now preserve unsaved translation drafts instead of saving or replacing them unexpectedly.
- Navigation continues to save pending edits before leaving the editor.

## Find glossary errors

- Select **Has glossary error** in the editor filter dropdown to show rows where a source glossary term has no matching accepted translation variant in the target text.
- The filter follows the existing red-highlight rules, including derived glossaries and terms that may be omitted, and works together with text search.
- Cached error results keep repeated filtering responsive in large chapters. Custom-HTML rows are excluded because they do not display glossary highlights.
