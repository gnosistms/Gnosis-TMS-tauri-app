# Gnosis TMS 0.8.151

## WordPress audio captions

- When you insert a WordPress audio link into a chapter, Gnosis TMS fills in the caption from your media library. If the audio has only a description, Gnosis TMS uses that text and keeps its links.
- Editing or saving text in the same row now preserves the imported caption. If you edit the caption yourself while it’s loading, Gnosis TMS keeps your edit.
