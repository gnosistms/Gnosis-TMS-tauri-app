# Gnosis TMS 0.8.116

## App updates no longer get stuck behind a sync

- "Restart to update" no longer refuses while a background sync with the git server is running or stalled. It still waits for unsaved editor changes and for in-progress project writes such as imports, creates, renames and rebuilds, which could be lost if the app restarted mid-write.
- "Check for Updates..." now says what is going on when an update is already downloading, downloaded, or being installed, instead of doing nothing.
- Update checks now time out (30 seconds per request, 90 seconds overall) so a stalled check reports an error instead of leaving the app on "Checking for updates..." indefinitely.
- The "Checking for updates..." notice is cleared when you start the download or restart before the check finishes, so it no longer lingers through the update.
