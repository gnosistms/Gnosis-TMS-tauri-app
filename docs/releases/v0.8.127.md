# Gnosis TMS 0.8.127

## PDF font fallback

- PDF export can use fonts already installed on your computer for characters
  missing from the selected fonts, including Egyptian hieroglyphs.
- Before approving a fallback font, review a PDF containing only the affected
  paragraphs, headings, captions, and footnotes, with fallback characters
  highlighted.
- Approved fallback fonts are remembered locally for all documents. When a
  document needs fallback fonts, you can manage those approvals in its PDF
  export dialog.

## Editing and preview

- Double-click text, images, captions, headings, footnotes, and other document
  blocks in Preview to open the corresponding place in the editor. The shared
  tooltip displays “Double-click to edit.”
- Footnotes use normal type at 70% opacity in the editor; intentional italic
  formatting is preserved.
- Image descriptions imported from a URL retain their hyperlinks. Glossary
  tooltip footnotes also display formatted links instead of raw HTML.

## Reliability and glossary research

- Running different Mac app versions side by side no longer removes a Git
  runtime that another version still needs.

- Native actions refresh expired sessions before starting and safely recover
  from an expired-session rejection, avoiding repeated writes and unnecessary
  sign-outs during connection problems.
- Glossary Research Studio supports reviewing, comparing, exporting, and
  resuming studies, with clearer progress and saved research history.
- Saving a research proposal preserves links between related glossary entries.
