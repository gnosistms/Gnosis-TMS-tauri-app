# Gnosis TMS 0.8.118

## More reliable local project removal

- Removing a local copy from Deleted projects now works during background refresh without showing a PROJECT LOAD FAILED error or hiding the projects page.
- Removal errors stay in the confirmation dialog, so you can retry without losing the project list.
- Stale refresh results no longer bring back removed projects. A later metadata check still recognizes a project restored by your team.
- If you switch teams or accounts while removal finishes, the result stays scoped to the original team and account.
