# Gnosis TMS 0.8.122

## Faster glossary updates in the editor

- Glossary terms you save are now available in the translation editor as soon as
  the local save completes. You can continue translating while the GitHub sync
  finishes in the background.
- Glossary highlights and AI glossary context refresh after the shared sync
  completes or a failed push is rolled back, so the editor reflects the final
  local state.
- Returning from glossary editing keeps the current translation rows and unsaved
  work while refreshing the linked glossary. Stale reads and navigation races no
  longer replace a newer glossary snapshot.
