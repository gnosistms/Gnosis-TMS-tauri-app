# Gnosis TMS 0.8.143

## Editor

- AI Translate All no longer erases the file's other languages. Since 0.8.132,
  each batch it saved wrote an empty value into every language of the row it
  was not translating, including the source: a Vietnamese pass emptied the
  Spanish, and a following English pass emptied the Vietnamese. The editor kept
  showing the old text until the chapter was reopened, so the loss could go
  unnoticed. Text lost this way can be brought back with Restore in each row's
  history.
- A New Term or Edit Term window opened from the editor (Save to glossary from
  highlighted text, or double-clicking a glossary term) now goes back to the
  chapter when it closes, instead of leaving you on the glossary page. A term
  opened from the glossary page still closes back onto it.

## AI Review

- The AI Review dialog has a second option, "Identify parts that are difficult
  to understand". It reads each unreviewed translation as its reader would,
  with the neighbouring rows and without the source, and never changes the
  text. Where part of a row is unclear or ambiguous, it marks the translation
  "please check" and adds an AI Review comment in the target language. Running
  it again skips the rows it already commented on unless their text has
  changed.
- That check is told which glossary terms the editor underlines in each row,
  so a row is not flagged just for containing technical terms.

## Glossary Research

- When step 9 needs a translation that is not approved yet, it shows the
  highlighted source and target sentence and asks whether to add the word to
  the approved translations. Yes approves it for that sentence's meaning only.
  No asks which translation to use instead, approves that one for the meaning,
  and later step 9 repairs use it.
- When the AI uses a word approved only for another meaning and the reviewer
  finds it right, step 9 asks whether to use the word for this meaning too,
  before any repair. Yes approves it and grades the saved answers again without
  new AI calls. "It has meaning …" moves the sentences to that meaning. No asks
  for the translation to use instead, and the occurrence is repaired as an
  error.

## Book export

- The footnote redundancy check on page 2 of the export dialog now also finds
  footnotes with identical text attached to different words, such as a
  synonym, a translation or another form of the same word. The AI still
  decides whether they explain the same thing; identical text alone, such as
  "Ibid.", is not enough. Books checked before are checked once more, reusing
  the AI's earlier decisions.
- The check no longer fails on a paragraph where two footnotes share one
  marker.
