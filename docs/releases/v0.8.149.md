# Gnosis TMS 0.8.149

## Editor headings

- Use H1 for a chapter title, H2 for a section and the new H3 style for a subsection. Hover over each style in the row toolbar to see its purpose.
- H3 is available in the heading filter, previews and document exports. HTML and Word imports now distinguish sections from subsections.
- Existing documents keep their saved headings. You can restyle individual rows in the editor whenever you choose.

## WordPress export

- For a standalone chapter, an opening H1 without footnotes supplies the post title. Sections export as H2 and subsections as H3. Any H1 retained in the body exports as H2, including a title with a footnote.
- When you export a whole book as one post, the book title supplies the post title. Chapter titles export as H2, sections as H3 and subsections as H4. The export dialog shows the mapping.
