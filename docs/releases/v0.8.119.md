# Gnosis TMS 0.8.119

## Updates that respect platform availability

- Gnosis only requires an update after confirming a compatible release is available for your platform.
- If a project, glossary, or QA list needs a newer version that is not available yet, its sync stays paused while the rest of the app remains usable.
- Restarting the app rechecks saved update requirements instead of restoring an update lock. Failed update checks, downloads, and installation attempts also release the lock.
- Installed updates now clear old notices even when another release is still being prepared for your platform.
- When a newer compatible release satisfies the requirement, Gnosis downloads that release instead of repeatedly requesting the old version.
