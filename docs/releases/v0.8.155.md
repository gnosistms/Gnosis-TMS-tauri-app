# Gnosis TMS 0.8.155

## Editor

- History groups AI revisions when the same translator marks a translation **Reviewed** or **Please check** between AI edits. Expand the group to see each revision and who made it, even if the translator switched models. The final human review stays visible.
- When another active row on the page already uses H1, the editor asks before applying H1 again. You can cancel and continue editing or choose **Set H1**.

## Glossary

- A standalone ellipsis in a target variant can span any number of words within a sentence. Hover either underlined part to see the complete saved translation, including the ellipsis.

- When you select translated text to make a glossary entry, the editor looks up the source wording using the model chosen in simplified AI settings or the Research model in detailed settings. The lookup can run without a pricing list. If the connection drops, the editor explains how to retry or enter the source term yourself.

## Windows

- **Send error reports** now covers native Windows crashes. When enabled, the app can send a crash stack trace to help diagnose unexpected exits.
