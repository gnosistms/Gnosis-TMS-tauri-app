# Gnosis TMS 0.8.137

## PDF and book layout

- Set H1 and H2 headings in capitals and raise H2 from 11.5pt to 12pt, so it no
  longer reads like the first line of body text. Headings sit one body line above
  their text, and book-chapter H1 headings keep their full space above. The editor
  and book previews match the PDF.
- Keep quotes of up to six lines on one page. Longer quotes split across pages like
  ordinary paragraphs instead of jumping whole to the next page, and a citation
  always stays with the last line of its quote.
- Give every quote block the same 1.5em space above and below in PDFs and the book
  preview, with or without a citation.

## Quotes and footnotes

- Set quote blocks upright everywhere, at 0.9 of body size and inset on both
  sides, as in the PDF. Italics written inside a quote now show. HTML, EPUB, Word,
  and RTF exports no longer force quotes into italics.
- Indent later paragraphs within a footnote by 1.5em, with no blank line needed
  between them. The paragraphs appear the same way in previews, glossary popovers,
  and PDF, HTML/WordPress, EPUB, DOCX, and RTF exports.

## Images and search

- Removing an image also removes its caption in that language. Chapter search and
  project search no longer match captions whose image is gone. Existing project
  search indexes rebuild once after updating.

## Updates and exports

- Clear a saved update prompt when that version is already installed, instead of
  reporting the release as unavailable.
- Keep the export preview's scroll position, focus, and selected text when a
  background project sync finishes.

## Maintenance

- Development builds optimize the image libraries, so preparing images for a PDF
  export takes seconds instead of minutes in the development app. Release builds
  are unchanged.
- Development startup keeps the development app's version in step with the latest
  release.
