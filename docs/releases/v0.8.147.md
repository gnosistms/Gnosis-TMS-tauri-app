# Gnosis TMS 0.8.147

## Resolving conflicts

- The conflict dialog now focuses on changed passages. Local and GitHub versions
  appear side by side with word-level additions and deletions, paragraph-break
  markers, and an editable result underneath. Unchanged translation text and
  footnotes are collapsed.
- Both versions are compared with their shared original when it is available.
  You can inspect that original, switch between rendered text and markup, and
  choose local or GitHub changes independently for each changed footnote.
- Compatible edits can be combined, including footnote paragraph spacing and
  link edits. Competing edits still need a choice or manual correction. Newly
  authored line breaks are preserved when combining with a spacing migration.
- Previous and Next move between conflicts while preserving your draft choices.
  Saving becomes available after every changed passage has a decision.
- The version columns align at the top. Save and finalize responds to the first
  click, shows its spinner immediately, and keeps the dialog's scroll position
  through saving and errors.

## History

- Consecutive revisions with the same text and underlying user are grouped,
  including AI-assisted and human edits by that user. Every revision is retained
  and can be expanded and restored.
- Expanded revisions show their individual author, including the model and user
  for AI edits. An indent and vertical line mark the group's entries.
- Revisions that only change status labels show “Text unchanged.” in the UI font,
  with their author, status changes, time and actions still visible.
- Attribution-only changes are correctly distinguished when identifying the
  current version, so an earlier attribution remains available to restore.

## Reviewing translations

- Unreview all closes its dialog and clears the visible reviewed markers
  immediately while saving continues. A failed save restores the persisted
  markers, and later individual changes keep their chosen state.
