# Gnosis TMS 0.8.136

## EPUB export

- Export individual chapters and arranged project books as reflowable EPUB ebooks.
- Preserve chapter order and optional numbering, linked contents and footnotes,
  inline formatting and ruby, author and translator metadata, and right-to-left
  reading direction.
- Embed images for offline reading, convert WebP images to PNG, and reuse duplicate
  images. The export pane explains how custom HTML is omitted or flattened.

## PDF layout

- Give quote attributions more space before the following text in chapter and
  book PDFs. Spacing scales with the body font size and avoids extra gaps at page
  boundaries.

## Glossary and QA fixes

- Prevent duplicate glossary source variants that differ only by capitalization,
  including entries created through the editor-row glossary button.
- Mark conflicting variants before saving and check again in native normal and
  research saves. Preserve entered spelling, punctuation, accents, and existing
  entries; previously saved duplicates are not merged automatically.
- Apply the same protection to case-insensitive plain QA terms while preserving
  explicit case-sensitive and regular-expression distinctions.

## Maintenance

- Fix the glossary browser regression fixture so overlapping synchronization
  checks share one preflight gate and cannot leave a waiting caller blocked.
