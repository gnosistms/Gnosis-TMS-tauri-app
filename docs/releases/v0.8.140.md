# Gnosis TMS 0.8.140

## Lists

- A new List row style turns a row into a list: each line is an item, and
  leading tabs set its level. The button in the field's corner picks bullets,
  numbers, letters or roman numerals. Return starts a new item, and Tab and
  Shift+Tab indent and outdent.
- Lists show in the preview and the book preview, in copied HTML, WordPress and
  plain text, and in every chapter export: HTML, EPUB, PDF, DOCX and Markdown
  set real lists, while RTF, TXT and Vellum get indented items that start with
  their markers.

## Book export

- Line breaks typed into the title page's Title field now apply only to the
  title page. Everywhere else the book is named (the EPUB's title, contents
  entries and section titles, the PDF running header and Vellum element names),
  the title is joined onto one line.
- The EPUB's title now comes from the title page, falling back to the project
  name when the title page has none, so a translated book's EPUB carries its
  translated title.
- Page 2 of the export dialog (redundancy checks) no longer flickers, reloads
  its thumbnails or loses its place when the projects page finishes refreshing.
- Edits made on page 1 of the export dialog while its shared settings are
  still loading are kept, instead of being reported as someone else's save and
  replaced.
- Separators in the PDF are the centred flourish instead of a full-width rule.
- H1 headings in the PDF are 14.5pt (up from 13pt), so they stand apart from
  12pt H2 headings.
- A quote's citation ends where the quote text ends, instead of at the page
  margin, and sits a quarter em further below the text it cites.
- To attribute body text, give an empty quote row an attribution. It is set
  under the text before it, at that text's margin, and the empty quote takes no
  space.
- Consecutive footnotes are a third of a line apart, so a new paragraph inside
  a note no longer looks like the start of the next note.

## Editor

- Inserting an image that is already used elsewhere in the project (by URL,
  upload or drop) now asks first, naming the files that use it. Tick "Don't
  show this warning again for this image" for images, such as separators, that
  you reuse on purpose.
- Headings in the editor and the preview match the PDF: regular-weight capitals
  for Latin scripts, and bold for Japanese, Korean, Chinese, Arabic and
  Persian. Separators show the same flourish as the PDF.
- Image captions are upright in every view and export. Italics written inside
  a caption are kept.
