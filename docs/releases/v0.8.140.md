# Gnosis TMS 0.8.140

## Book export

- Line breaks typed into the title page's Title field now apply only to the
  title page. Everywhere else the book is named (the EPUB's title, contents
  entries and section titles, the PDF running header and Vellum element names),
  the title is joined onto one line.
- The EPUB's title now comes from the title page, falling back to the project
  name when the title page has none, so a translated book's EPUB carries its
  translated title.
- Page 2 of the export dialog (redundancy checks) no longer flickers, reloads
  its thumbnails or loses its place when the projects page finishes refreshing.

## Editor

- Inserting an image that is already used elsewhere in the project (by URL,
  upload or drop) now asks first, naming the files that use it. Tick "Don't
  show this warning again for this image" for images, such as separators, that
  you reuse on purpose.
