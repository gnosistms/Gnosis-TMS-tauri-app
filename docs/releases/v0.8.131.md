# Gnosis TMS 0.8.131

## Glossary popups

- Keep translator notes and footnotes beside the content they describe. Global
  notes are labeled "Note to Translators:"; footnotes receive a "Footnote:"
  label when both kinds of note are present.
- Indent translation usage notes beneath their translation in source-language
  popups. Hide usage notes in target-language popups, where only the matched
  translation is shown.

## AI Assistant review

- Review all current target-language text: the body, numbered footnotes, and
  image captions. Footnote and caption corrections stay separate from body-text
  drafts so applying a body draft preserves its scope.

## Smart quotes and saving

- Convert straight quotes when leaving a body, footnote, or caption editor,
  including when the wording has not changed. Other untouched language columns
  and review flags are preserved.
- Use one deferred save on blur, avoiding duplicate writes and preserving newer
  focused drafts while an earlier save finishes.

Version 0.8.130 was not published; this release includes its intended changes.
