# Gnosis TMS 0.8.117

## New projects stay usable while syncing

- Newly created projects are ready for local work as soon as creation completes,
  while discovery and repository sync continue in the background.
- Background refreshes preserve the readiness of local projects, including empty
  projects, instead of making them appear unavailable.
- The first sync preserves locally imported files and edits, keeps project layout
  metadata intact, and handles repositories whose default branch is not `main`.
- A slow or stalled sync keeps its place in the write queue so imports and other
  project writes do not overlap unfinished native operations.
- Failed project deletion keeps the project list visible and reports the error
  without clearing the page.

## Admin project creation

- The accompanying server fix allows team Admins to create projects. It is already
  deployed and also applies to earlier app versions; Owner-only permissions are
  unchanged.
