# Gnosis TMS 0.8.106

## Simpler export and search controls

- WordPress export now has one export action. The extra **Refresh images and
  export** button is removed; normal export continues to check image references
  automatically.
- Project search offers **Show more results** below the results instead of an
  extra toolbar button. Choose **Show fewer results** to return to stronger matches.
- The alternate WordPress.com login option is now a text link during site setup.

The orange update indicator, retry actions, and sample-download links are unchanged.
