# Gnosis TMS 0.8.123

## See what changed after your last edit

- A new editor filter, **Changed after my last edit**, lists the rows another
  person changed after you last edited them. Rows you never edited are listed
  when someone else changed them. Reviewed and "Please check" marks and comments
  don't count as changes; AI edits count for whoever started them.
- Each listed row shows what changed since your last edit: new text in green,
  removed text struck through in red, with bold, italic and other formatting
  kept. A formatting-only change is highlighted, and hovering it shows the old
  formatting. Added and removed footnotes, captions and images are marked the
  same way, and a changed text style is shown on the style buttons.
- The rows stay on screen while you work on them, until you change the filter.
  Changes that arrive by sync add rows to the list.

## Claude for every AI feature

- Claude Opus 5.5 now works for AI Translate, Translate All, AI Review, Review
  All, the AI Assistant and add-translation alignment.
- AI requests that take longer than a minute no longer get cut off, for Claude
  and OpenAI alike.
- Running out of Claude credits shows the same clear message and billing link as
  OpenAI.
- With Claude, the AI Assistant reuses cached conversation context, so
  follow-up questions cost less. With OpenAI, follow-up questions no longer fail
  and retry once behind the scenes.
- The default OpenAI model is now GPT-6 Astra.
- Structured AI answers are requested in a fixed field order, which makes
  alignment and Review All more reliable on both providers.
