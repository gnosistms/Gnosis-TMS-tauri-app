# Gnosis TMS 0.8.104

## AI translation batches are safer

AI Translate All now gives rows simple labels within each batch, such as `1`
through `15`, instead of long internal identifiers. This makes it easier for
models to keep each result attached to the correct row.

Before applying a batch, Gnosis now checks that the response includes every
expected label exactly once. If a response is incomplete or has duplicate or
unexpected labels, none of that batch is written; Gnosis falls back to its
existing individual translation recovery for those rows.

Successful batches keep the same batch size, parallelism, and grouped saving.
