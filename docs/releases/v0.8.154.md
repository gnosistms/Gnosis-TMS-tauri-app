# Gnosis TMS 0.8.154

## Project refresh

- When you reopen a project after time away, a clean local copy picks up changes already on GitHub before the app applies any remaining data migrations.
- If you have unpublished commits in a compatible project, sync replays them against the latest GitHub copy before checking which content migrations still apply.
- After an interrupted Git sync, the app can restore the GitHub copy and keep the entire previous local project, including unpublished work. Conflicting translations that the editor can read are available for review. The Projects screen shows where the original files were saved.
- Search continues to return results from readable translation rows while a damaged row is being recovered. A later refresh includes the row once it can be read again.
