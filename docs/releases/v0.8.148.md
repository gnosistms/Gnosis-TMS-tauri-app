# Gnosis TMS 0.8.148

## History

- Consecutive edits by the same user collapse into one expandable group even
  when the translation text changes. Another user's intervening edit starts a
  separate group.
- Contiguous human and AI groups controlled by the same user can also collapse
  together when the AI edits leave the text unchanged. AI edits that change
  the text remain in their own group.
- Every revision remains available when expanded, with its individual author,
  status changes and restore actions.
- Changing your display name no longer splits a contiguous run when your
  account identity is unchanged.
- Previously expanded revisions stay visible if a new AI text edit splits a
  combined group.
