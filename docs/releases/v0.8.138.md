# Gnosis TMS 0.8.138

## Paragraphs inside a row

- A blank line inside a row's text now starts a new paragraph. Each paragraph is
  set as its own block in the editor, the Translate and book previews, and every
  export (PDF, DOCX, RTF, EPUB, HTML, Markdown, plain text, WordPress, and
  Vellum). Rows that already separate paragraphs with a blank line now show them
  as real paragraphs. A single return is still a line break, so verse and lists
  look the same as before.
- In a row's text, Return starts a new paragraph and Shift+Return inserts a line
  break. Save and leave the field with Command+S on macOS or Ctrl+S elsewhere; the
  hint under the field names the key.
- Subtitle text and custom HTML rows are not split. Footnotes, captions, and
  attributions work as before.

## PDF and book layout

- When a chapter opens with a quote or an image, it gets a page of its own beneath
  the chapter title, and the chapter text starts on the next page. A one-line
  cover quote is centred, and a cover image shrinks to fit under the title. The
  book preview shows the cover as its own page.
- Drop caps drop as many lines as the opening paragraph has: three lines for three
  or more, two for two, and none for a one-line paragraph. The preview's drop cap
  now lines up with the first line, as in the PDF.
- A footnote may run over to the next page with a single line, instead of pushing
  the line that references it onto the next page and leaving a gap above the
  footnotes.

## EPUB export

- A web image that can't be fetched no longer stops the export. The book shows a
  short notice in its place and keeps the caption.
- Photos are compressed sensibly: opaque WebP images are stored as JPEG and very
  large images are scaled down. One image-heavy chapter went from 294 MB to 43 MB.
- The export window shows image progress while an EPUB is being written.

## Images

- Repair uploaded images that the 0.8.10 layout update left in old per-row
  folders, which made PDF and EPUB export report a missing image. Each project
  repo is repaired once, on its first sync after updating. Any image the repair
  cannot place safely is left unchanged and listed in
  `.gtms/image-path-repair.json`.
- The 0.8.75 image path repair no longer points a missing image at another
  chapter's image that happens to have the same name.
