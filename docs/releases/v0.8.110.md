# Gnosis TMS 0.8.110

## Smoother project updates

- Project-page scrolling stays responsive while repositories update in the background.
- Unchanged repository sync polls no longer rebuild the projects page.
- Changed sync state renders once, and completed updates remain visible after choosing a chapter status or glossary from a dropdown.

## Search reliability and error reporting

- Search-index refreshes coordinate database writes and commit atomically, reducing database-lock failures during overlapping refreshes.
- Expected glossary and QA term validation errors and unsupported spreadsheet language headers no longer generate error reports.
- Browser test failures no longer send telemetry to the production Sentry project.

## PDF export

- Quote and blockquote text now renders in italics in exported PDFs.
